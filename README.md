# Alpha Kappa Psi · Beta Upsilon

Official website for the Beta Upsilon Chapter of Alpha Kappa Psi at the University of South Carolina.

**Live site:** https://akpsi-beta-upsilon-site.lovable.app

## Overview

A modern, responsive marketing site for AKPsi's premier co-ed professional business fraternity at USC. Built with React, TanStack Start, and Tailwind CSS.

## Tech Stack

- React 19 + TanStack Start
- TypeScript
- Tailwind CSS
- Vite

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Deployment

Pushes to the connected GitHub repository automatically redeploy the live site via Vercel.
